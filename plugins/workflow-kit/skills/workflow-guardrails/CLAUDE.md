# Editing the `workflow-guardrails` skill

**Do NOT hand-edit this skill.** It is GENERATED from `.claude/rules/*.md` by
`scripts/build-skill.mjs`. Edit the rules, then regenerate:

```bash
npm run build:skill
```

`npm run check` (also in CI) fails the commit if this skill drifts from `.claude/rules/`. A
hand-edit here is lost on the next build — change the source rule instead.
