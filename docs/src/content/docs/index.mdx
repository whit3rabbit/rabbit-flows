rabbit-flows is an `npx` installer that copies Claude Code dynamic workflows into `.claude`, along with the skills and agents each workflow requires. It records a receipt so it can uninstall only the files it placed.

**Requirements:** Claude Code v2.1.154+, dynamic workflows enabled in `/config`, Node.js 18+.

**One-line install:**

```bash
npx @whit3rabbit/rabbit-flows
```
